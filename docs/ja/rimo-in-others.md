# その他のツールで Rimo を使う

[English](../en/rimo-in-others.md) | [日本語](../ja/rimo-in-others.md)

Rimo は、サイドバーに個別のページがあるツール以外でも使えます。このページではそれらをまとめています。お使いのツールを選んで、その手順を参照してください。

| ツール | できること | ガイド |
|--------|-----------|--------|
| **Genspark** | Super Agent からミーティングや過去のノートについて質問できます。Rimo は **Community & Custom** にカスタムMCPサーバーとして自分で追加します。 | [Genspark](rimo-in-genspark.md) |
| **Notion** | ミーティングについて質問し、過去のノートから情報を見つけられます。MCP コネクションを利用できるプランのワークスペースが必要です。 | [Notion](rimo-in-notion.md) |
| **Slack** | ミーティングの内容、決定事項、アクションアイテム、過去の議論について質問できます。Rimo を参照できるかはワークスペースの設定によって変わります。確認する項目はガイドで説明しています。 | [Slack](rimo-in-slack.md) |

> **この一覧は増えていきます。** 各ツールは動作確認が取れ次第、専用のページを用意してここに追加します。お使いのツールがまだ載っていない場合でも、[ホスト型 MCP サーバー](mcp.md) はリモート MCP に対応したクライアントであれば利用できます。手動で接続する例としては [Microsoft Copilot で Rimo を使う](rimo-in-microsoft.md) が最も近い手順です。
